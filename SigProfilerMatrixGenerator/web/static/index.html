Turn variant calls into mutational matrices

Choose a folder of VCF, MAF or simple text files and the reference genome they were called against. The run writes SBS, DBS and ID matrices you can plot here, or take on to SigProfilerExtractor and SigProfilerAssignment.

1

Input

a folder of VCF, MAF or Txt files, recognised automatically
2

Project

names the matrix files
The output folder appears here once an input is chosen.
3

Reference genome

the assembly your variants were called against
Status
4

Matrices

one set for each type of mutation in your calls
Standard matrices
Written for each type of mutation present: SBS matrices for single base substitutions, DBS for doublet substitutions, ID for small insertions and deletions. A cohort with no doublets, for example, gets no DBS matrices. Each is a .all file with one column per sample.
Exome only
Keeps only mutations inside the exome, within a 100 bp cushion. Files end in .exome instead of .all.
Strand bias test
Compares transcribed with untranscribed mutations for the 24, 384 and 6144 contexts and writes enrichment, p values and FDR q values to TSB/.
PDF plots
SigProfilerPlotting draws every SBS, DBS and ID matrix the run writes, one page per sample, into plots/. The same as plot=True in Python or --plot on the command line. Adds time for large cohorts.
ID89 and ID476
Extra indel count matrices in the Koh et al. (2025) classification. ID83 is unchanged. These are categories, not signatures.

Getting started

          
A run reads a folder of variant calls, assigns every mutation to its
            context against the reference genome, and writes one matrix per context
            with a column for each sample. Everything happens on this computer.

        


        

          
1. Choose the input

          

            
Point at one folder. Every file in it is read, so keep one cohort,
              in one format, per folder.

            

              
.vcf
One file per sample. The sample is named after the file.

              
.maf
One or more MAF files. Samples come from Tumor_Sample_Barcode.

              
.txt
SigProfiler simple text: project, sample, ID, genome, type,
                chromosome, start, end, ref, alt.

            

            
The page reads the folder as soon as you choose it and reports the format,
              the number of samples and the number of calls before anything runs.

          

        


        

          
2. Install the reference genome

          

            
Matrices need the reference the calls were made against. The genome card
              says whether it is installed. A missing genome can be installed from there,
              or as the first step of the run. Installs are large and download once.

            
The same install, from a terminal:

            
SigProfilerMatrixGenerator install GRCh38

          

        


        

          
3. Read the results

          

            
A finished run opens in Results. Choose a context to plot it for any
              sample, in counts, percent or proportion. The camera button above a chart
              saves it as SVG.

            

              
SBS/
Single base substitutions, SBS6 to SBS6144.

              
DBS/
Doublet base substitutions, DBS78 to DBS2400.

              
ID/
Small insertions and deletions: ID28, ID83 and ID415.

              
TSB/
Strand bias statistics, when the test was run.

              
plots/
PDF figures from SigProfilerPlotting, when PDF plots was ticked.

              
vcf_files/
Every mutation with the context it was assigned.

            

          

        


        

          
4. Stop the app

          

            
Use Quit in the top bar, or run ./launch_web.sh --stop.
              Quitting stops any run still in progress. Matrices already written stay where they are.
