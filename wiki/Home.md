# SigProfilerMatrixGenerator

SigProfilerMatrixGenerator creates mutational matrices for all types of somatic mutations from whole-genome sequencing, whole-exome sequencing, and targeted sequencing data.

## Prerequisites

- **Internet Connection**
- **Python** - v3.4+
- **pandas** - any version (automatically installed with SigProfilerMatrixGenerator)
- **Wget** - v1.9
- **SigProfilerPlotting** - latest version (automatically installed with SigProfilerMatrixGenerator)
- **Reference genomes** - At least one reference genome file must be downloaded and installed prior to use

## Upgrades

If there is an updated version of the tool, use the following command:

```bash
pip install SigProfilerMatrixGenerator --upgrade
```
